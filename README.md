# Manufacturing & Design — 3-Minute Research Video Showcase

## Setup Instructions

### 1. Rename and add video files

Download the 6 videos from Google Drive and rename them as follows:

| Original filename | Rename to |
|---|---|
| IISE2026LoganHeck.mp4 | `heck.mp4` |
| IISE 2026 M&D 3-Minute Showcase Submission – Yihan Huang (1).mp4 | `huang.mp4` |
| IISE 2026 M&D 3-Minute Showcase Submission – [Donghyun Ko].mp4 | `ko.mp4` |
| Timothy.mp4 | `kuo.mp4` |
| IISE 2026 M&D 3-Minute Showcase Submission – Evans Nyanney.mp4 | `nyanney.mp4` |
| Mahjabin.mp4 | `rahman.mp4` |

Place all 6 renamed files in the `videos/` folder.

### 2. Enable GitHub Pages

1. Go to your repository **Settings** → **Pages**
2. Under **Source**, select **Deploy from a branch**
3. Select **main** branch, root folder `/`
4. Click **Save**
5. Your site will be live at `https://YOUR-USERNAME.github.io/REPO-NAME/`

### 3. Share the link

Anyone with the link can watch all 6 videos in a continuous auto-playing loop.

## Features

- One-click start, then fully hands-free
- Auto-advances to next video when each one ends
- Loops continuously
- Progress bar and countdown timer
- Click any presenter name to jump to their video
- Pause/Resume, Prev/Next controls
